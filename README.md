# AI-Based Emergency First Aid Assistance System

## Overview
An AI-powered web application that provides emergency first aid guidance based on injury images and user descriptions. The system recommends first aid according to injury severity and the availability of first aid kits while implementing cybersecurity features for secure user data management.

## Features
- User Registration & Login
- AI-assisted injury analysis
- Image upload
- Injury description input
- Severity-based first aid guidance
- Basic and Advanced first aid kit support
- Secure authentication
- Modern healthcare-themed interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API
- AI Image Analysis
- Cybersecurity Concepts
